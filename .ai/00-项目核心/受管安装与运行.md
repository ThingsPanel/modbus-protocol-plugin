# 受管安装与运行

受管运行代码、平台双协议登记和签名候选流程已在本地实现。签名发布和环境验收待执行。

- 插件目录使用单一 `modbus` 条目。平台为安装代次签发一个 `MODBUS` 身份，登记 `MODBUS_TCP` 和 `MODBUS_RTU` 两个协议，保留已有协议记录 ID。
- 受管进程使用平台注入的运行时令牌和独立 MQTT 凭据。旧模式沿原启动入口运行。受管模式缺少凭据时启动失败。
- 设备查询限于启用且已激活的 Modbus 网关，以及同租户、同协议的直接子设备。采集报文沿用现有格式。MQTT 权限按设备归属授予，失效代次不得访问平台。
- 设备 TCP 接入由安装环境的受控入口转发，平台表单回调及健康检查通过容器内网访问。签名目录保留 HA 和 HTTP，Modbus 追加固定镜像摘要。
- 验收需覆盖安装、TCP/RTU 注册、上报入库、下行写入、停用撤销及旧插件兼容。

入口为本仓库的 `Dockerfile.managed`、`configs/managed.yaml`，以及安装器的 `docs/MODBUS-MANAGED.md`。本地已验证受管 HTTP 客户端、平台作用域、协议登记与健康失败清理。Linux amd64 和 arm64 交叉编译通过。
